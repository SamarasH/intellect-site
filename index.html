How it's built

Research → Plan → Implement

A lead agent scopes the market, then specialist agents each web-research one workstream and return source-traced findings. An adversarial verifier tries to refute the decision-critical claims, and only then does a synthesizer write the executive read — from verified claims alone.

1

Value Chain

Routes to market and the price build-up from end-user price back to ex-works.

2

Demand

The end-user demand equation, growth drivers vs barriers, and what would have to be true.

3

Market Size

≥2 independent pathways, reconciled on one declared basis — the answer is a range.

4

Participants

Who plays at each stage, their share of the sized market, and concentration.

5

Regulatory

The named regulations, tailwind vs headwind, on a timeline, with macro sensitivity.

6

Verification

An adversarial audit that searches independently to refute the key claims.

7

Synthesis

The executive read — written only from claims that survived verification.

Every figure carries a confidence label:

CONFIRMED — ≥2 independent sources RESEARCHED — one cited source HYPOTHESIS — estimate, shown as a range CONFLICTING — sources disagree
Under the hood

A reusable data stack, not a prompt

The differentiation from a plain LLM is the data layer: 70+ typed clients over public market-intelligence and financial sources (Eurostat, EAFO, ACEA, GLEIF, UN Comtrade, FRED, USGS, USPTO and more), entity resolution, cross-signal triangulation and source-traced records. The agents only ever reason over data that has already been retrieved and cited — so a number that can't be traced is never stated.
